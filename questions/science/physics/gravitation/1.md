**The linear momentum and position vector of the planet is perpendicular to each other at**

```markdown
At perihelion (closest to Sun) and aphelion (farthest from Sun), the velocity of the planet is perpendicular to the position vector from the Sun. This is because at these points, the motion is tangential while the position vector is radial, making them perpendicular to each other.
```
