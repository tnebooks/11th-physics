---
choices:
  - $T_1 = T_2$
  - $T_1 = 6T_2$
  - $T_1 = 3T_2$
answers:
  - $T_1 = \frac{T_2}{6}$
---

**An ideal gas passes from one equilibrium state (P₁, V₁, T₁, N) to another equilibrium state (2P₁, 3V₁, T₂, N). Then**

```markdown
Using the ideal gas equation PV = NkT. For state 1: P₁V₁ = NkT₁. For state 2: (2P₁)(3V₁) = NkT₂, so 6P₁V₁ = NkT₂. Dividing: 6(NkT₁) = NkT₂, so T₂ = 6T₁, therefore T₁ = T₂/6.
```
