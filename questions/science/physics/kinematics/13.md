choices:
  - $\frac{u^2}{2g}$
  - $\frac{u^2}{g}$
  - $\frac{u}{2g}$
answers:
  - $\frac{2u}{g}$
---

**If an object is thrown vertically up with the initial speed u from the ground, then the time taken by the object to return back to ground is**

```markdown
The time of flight for an object thrown vertically upward with initial velocity u is given by T = 2u/g. This is the time to go up and come back down.
```
