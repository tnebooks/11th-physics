**If one object is dropped vertically downward and another object is thrown horizontally from the same height, then the ratio of vertical distance covered by both objects at any instant t is**

```markdown
Both objects have the same initial vertical velocity (0) and both are accelerated downward by gravity (g). The vertical distance covered by both objects is given by y = ½gt², which is the same for both. Therefore, the ratio of vertical distances is 1:1.
```
