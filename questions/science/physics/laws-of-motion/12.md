choices:

answers:
  - static friction is not zero and kinetic friction is zero

**When an object is at rest on the inclined rough surface,**

```markdown
When an object is at rest on an inclined rough surface, static friction acts to balance the component of weight along the incline, so static friction is not zero. Kinetic friction is zero because the object is not moving.
```
