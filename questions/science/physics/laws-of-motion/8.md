**Two blocks of masses m and 2m are acted upon by forces F₁ and F₂ as shown. If both blocks experience the same acceleration, then the ratio F₁:F₂ is (Physics Olympiad 2016)**

![](img3.png)

```markdown
Using Newton's second law F = ma. For the block of mass m, F₁ = ma. For the block of mass 2m, F₂ = (2m)a. Therefore, F₁/F₂ = ma/(2ma) = 1/2. So the ratio F₁:F₂ = 1:2.
```
