**A particle executes simple harmonic motion and displacement y at time t₀, 2t₀ and 3t₀ are A, B and C respectively. Then the value of (A + C)/(2B) is**

```markdown
Let y = a sin(ωt + φ). Then A = a sin(ωt₀ + φ), B = a sin(2ωt₀ + φ), C = a sin(3ωt₀ + φ). Using the identity sin(A+B) + sin(A-B) = 2 sin A cos B. Here A + C = a[sin(ωt₀ + φ) + sin(3ωt₀ + φ)] = 2a sin(2ωt₀ + φ) cos(ωt₀) = 2B cos(ωt₀). Therefore, (A + C)/(2B) = cos(ωt₀).
```
