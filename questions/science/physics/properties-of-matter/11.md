**Copper of fixed volume V is drawn into a wire of length l. When this wire is subjected to a constant force F, the extension produced in the wire is Δl. If Y represents the Young's modulus, then which of the following graphs is a straight line? (NEET 2014 model)**

```markdown
Extension Δl = Fl/(AY). Since volume V = Al, A = V/l. So Δl = Fl²/(VY). For fixed V and Y, Δl ∝ l². So Δl versus l² is a straight line. Also, for fixed l, Δl ∝ F, so Δl versus F is a straight line.
```
