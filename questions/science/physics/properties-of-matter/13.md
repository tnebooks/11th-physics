**The following four wires are made of the same material. Which of these will have the largest extension when the same tension is applied?**

```markdown
Extension Δl = FL/(AY) = FL/(πr²Y). For same material (Y same) and same tension F and same length L, extension is inversely proportional to r². The wire with the smallest diameter (0.5 mm) will have the largest extension.
```
