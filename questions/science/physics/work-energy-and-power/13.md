**A particle is placed at the origin and a force F = kx is acting on it (where k is a positive constant). If U(0) = 0, the graph of U(x) versus x will be (where U is the potential energy function) (IIIT 2004)**

![](img.png)

```markdown
Force F = -dU/dx. Given F = kx, so -dU/dx = kx, which gives dU/dx = -kx. Integrating, U = -½kx² + C. Since U(0) = 0, C = 0. So U = -½kx². This is a downward parabola, which corresponds to option (c).
```
